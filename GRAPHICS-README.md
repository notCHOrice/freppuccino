# Freppuccino

Rhino 9 plugin (RhinoCommon, net10.0).

```sh
dotnet build                               # -> src/Freppuccino/bin/Debug/net10.0/Freppuccino.rhp
dotnet run --project src/Freppuccino       # builds + launches Rhino 9, plugin auto-loaded, all views in Freppuccino mode (VS Code: F5 does the same)
```

Command: `Freppuccino` (switches active viewport to the Freppuccino shader display mode). Design: `docs/viewport-shaders.md`; Windows validation: `docs/windows-validation.md`.
